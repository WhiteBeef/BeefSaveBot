# BeefSaveBot

Telegram-бот, который скачивает видео и музыку по ссылке, ищет треки по названию и конвертирует файлы.

- **Видео:** YouTube (видео и Shorts), TikTok (видео и слайд-шоу, склеенные под музыку), Instagram (рилсы и посты).
- **Музыка:** Яндекс Музыка, SoundCloud, YouTube Music — по ссылке или поиском по названию.
- **Настройки пользователя** (`/settings`): качество, формат (MP4, MP3, WEBM, WEBP) и сервис, где сначала искать музыку.
- **Обрезка** с точностью до кадра: `/crop <ссылка> <начало> <конец>`.
- **Конвертер файлов и архивов:** изображения, видео, аудио, документы, таблицы, презентации, данные.
- **Работа в любом чате:** инлайн-режим `@бот ссылка`, `/save` в ответ на сообщение со ссылкой, упоминание в группах.
- **Админка для одного администратора:** статистика, история запросов, пользователи, баны, рассылка, выгрузка в CSV.

## Что нужно

- Сервер с Linux (проверялось на Ubuntu 24.04) и доступом в интернет.
- **Docker** с плагином **Compose** (`docker compose`).
- **JDK 21** — jar собирается на хосте через `./mvnw`, а в образ копируется уже готовый.
- Около 3 ГБ на диске под образ: ffmpeg, ImageMagick, LibreOffice.

На чистой Ubuntu JDK и Docker ставит одна команда (см. шаг 3).

## Деплой

### 1. Создайте бота в @BotFather

1. `/newbot` — получите **токен** и **username** бота.
2. `/setinline` → выберите бота → отправьте текст подсказки, например `Ссылка на видео`. Без этого не будет работать инлайн-режим (`@бот ссылка` в любом чате).
3. `/setinlinefeedback` → выберите бота → **Enabled**. Без этого скачивание в инлайн-режиме придётся запускать кнопкой на заглушке.
4. `/setprivacy` → выберите бота → **Disable**. Нужно, чтобы `/save` в группах видел сообщение, на которое отвечают. После смены настройки **удалите бота из группы и добавьте заново**. Реагировать на обычные сообщения бот при этом не начнёт: в группах он отвечает только на `/save` и на упоминание.

Свой Telegram ID для админки можно узнать у [@userinfobot](https://t.me/userinfobot).

### 2. Скачайте код и заполните `.env`

```bash
git clone https://github.com/WhiteBeef/BeefSaveBot.git
cd BeefSaveBot
nano .env
```

Минимальный `.env`:

```env
TELEGRAM_BOT_TOKEN=123456789:AA...
TELEGRAM_BOT_USERNAME=BeefSaveBot
TELEGRAM_ADMIN_ID=123456789
```

Все переменные описаны в разделе [Настройки](#настройки). Файл `.env` уже в `.gitignore`: токены не попадут в репозиторий.

### 3. Запустите

На сервере, где уже стоят JDK 21 и Docker:

```bash
make deploy
```

На чистой Ubuntu (сначала поставит OpenJDK 21 и Docker через официальный скрипт get.docker.com, для этого нужен `sudo`):

```bash
make start
```

Если после установки Docker `make deploy` пишет `permission denied` на `docker.sock`, выполните `sudo usermod -aG docker $USER`, перелогиньтесь и запустите `make deploy` ещё раз.

`make deploy` собирает jar, пересобирает Docker-образ (заодно ставит свежий yt-dlp) и перезапускает контейнеры. Postgres поднимается рядом, миграции базы применяются автоматически при старте.

Проверьте, что бот запустился:

```bash
make logs
```

После этого напишите боту `/start`.

## Обновление

```bash
git pull
make deploy
```

Пересобирайте образ, даже если в коде ничего не менялось, когда начинает отваливаться YouTube, TikTok или Instagram: эти сайты часто меняются, и свежий yt-dlp обычно уже умеет с ними работать. yt-dlp обновляется при каждом `make deploy`.

## Команды Makefile

| Команда | Что делает |
|---|---|
| `make deploy` | Собрать jar → пересобрать образ → перезапустить контейнеры |
| `make start` | Поставить JDK 21 и Docker (Ubuntu), затем `deploy` |
| `make logs` | Логи бота в реальном времени |
| `make up` / `make down` | Поднять / остановить контейнеры |
| `make build` | Только собрать jar |
| `make dev` | Запуск для разработки (`docker-compose.dev.yml`, отладка на порту 5005) |
| `make clean` | Удалить сборку, контейнеры, образ **и данные базы** |

## Настройки

Все переменные задаются в `.env`. Обязательные — только первые две.

### Бот

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | Токен от @BotFather |
| `TELEGRAM_BOT_USERNAME` | — | Username бота без `@` |
| `TELEGRAM_ADMIN_ID` | пусто | Telegram ID единственного администратора. Пусто — админка выключена, инлайн-режим тоже не будет работать (см. `TELEGRAM_STORAGE_CHAT_ID`) |
| `TELEGRAM_STORAGE_CHAT_ID` | чат админа | Чат, куда бот загружает файлы для инлайн-режима и сразу их удаляет. Чтобы эти сообщения не мелькали в личке, создайте приватный канал, добавьте бота админом и укажите ID канала (`-100…`) |
| `TELEGRAM_BOT_AUTHOR` | `@WhiteBeef` | Автор в `/start` и сообщениях об ошибках |
| `TELEGRAM_BOT_GITHUB_URL` | ссылка на этот репозиторий | Ссылка на исходный код в `/start`; пусто — не показывать |
| `BOT_TIMEZONE` | `Europe/Moscow` | Часовой пояс для дат в админке |

### Скачивание

| Переменная | По умолчанию | Описание |
|---|---|---|
| `YANDEX_MUSIC_TOKEN` | пусто | OAuth-токен Яндекса. Без него Яндекс Музыка отключена, поиск идёт по SoundCloud и YouTube Music |
| `DOWNLOAD_YT_DLP_COOKIES_FILE` | пусто | Путь к cookies для Instagram внутри контейнера, например `/app/cookies/cookies.txt` (см. ниже) |
| `DOWNLOAD_YT_DLP_USER_AGENT` | пусто | Свой User-Agent для запросов yt-dlp к Instagram |
| `DOWNLOAD_MAX_HEIGHT` | `1080` | Максимальное разрешение видео (по короткой стороне) |
| `DOWNLOAD_MAX_RESOLUTION` | `1080` | То же для TikTok |
| `DOWNLOAD_SOURCE_MAX_BYTES` | `524288000` | Сколько можно скачать исходника для обрезки и MP3 (500 МБ). Результат всё равно ограничен 50 МБ — это лимит Telegram |
| `DOWNLOAD_FFMPEG_TIMEOUT_MINUTES` | `15` | Лимит времени на обрезку и конвертацию |
| `DOWNLOAD_CACHE_ENABLED` | `true` | Кэш отправленных файлов: повторный запрос той же ссылки (с теми же форматом, качеством и фрагментом) от любого пользователя отдаётся мгновенно, без скачивания. Файлы хранятся в Telegram, в базе только их `file_id`. `false` — выключить |
| `DOWNLOAD_CACHE_HOURS` | `0` | Срок жизни записи кэша в часах. `0` — бессрочно |
| `DOWNLOAD_SLIDESHOW_SECONDS_PER_SLIDE` | `3` | Сколько секунд показывается слайд в видео из слайд-шоу TikTok |
| `DOWNLOAD_SLIDESHOW_FALLBACK_API` | `true` | Разрешить запасной сторонний сервис tikwm.com для TikTok, когда не справились страница поста и yt-dlp |

### Сборка образа

| Переменная | По умолчанию | Описание |
|---|---|---|
| `INSTALL_LIBREOFFICE` | `true` | `false` — собрать образ без LibreOffice: он меньше примерно на 600 МБ, но без конвертации документов, таблиц и презентаций |

### Токен Яндекс Музыки

Нужен аккаунт с подпиской Яндекс Плюс, иначе будут доступны только 30-секундные превью. Один из способов получить токен — открыть в браузере, где вы вошли в Яндекс:

```
https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
```

После подтверждения токен будет в адресной строке после `access_token=`. Скопируйте его в `YANDEX_MUSIC_TOKEN`. Это неофициальный способ, которым пользуются сторонние клиенты Яндекс Музыки.

### Cookies для Instagram

Если Instagram начинает требовать вход (`login required`, `rate-limit`):

1. Экспортируйте cookies из браузера, где вы вошли в Instagram, в формате Netscape (`cookies.txt`), например расширением «Get cookies.txt LOCALLY». Лучше использовать отдельный аккаунт.
2. Положите файл в папку `cookies/` рядом с `docker-compose.yml`: она монтируется в контейнер как `/app/cookies`.
3. Добавьте в `.env` строку `DOWNLOAD_YT_DLP_COOKIES_FILE=/app/cookies/cookies.txt` и выполните `make up`.

## Админка

Доступна только пользователю с `TELEGRAM_ADMIN_ID`. Команды видны в меню только у него:

`/admin` — панель с кнопками · `/stats` · `/requests` · `/byusers` · `/errors` · `/users` · `/user <id|@username>` · `/find <текст>` · `/ban` / `/unban` · `/send <id> <текст>` · `/broadcast <текст>` · `/export`

## Резервная копия базы

```bash
# Сохранить
docker exec tgbot_postgres pg_dump -U postgres telegrambot > backup.sql
# Восстановить
docker exec -i tgbot_postgres psql -U postgres telegrambot < backup.sql
```

## Безопасность

В `docker-compose.yml` у Postgres стоит пароль `postgres`, и порт `5432` открыт наружу. Если база не нужна вам снаружи, закройте порт: уберите блок `ports` или замените его на `"127.0.0.1:5432:5432"`. Если нужна — смените пароль в обоих сервисах.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| Перестал качаться YouTube, TikTok или Instagram | `make deploy` — обновит yt-dlp. Смотрите `make logs` |
| Instagram пишет `login required` или `rate-limit` | Добавьте cookies (см. выше) |
| Инлайн-режим не показывает подсказку | Проверьте `/setinline` в BotFather и что задан `TELEGRAM_ADMIN_ID`; админ должен хотя бы раз написать боту `/start` |
| Инлайн-сообщение висит на «⏳ Скачиваю…» | Включите `/setinlinefeedback` или нажмите кнопку на заглушке |
| `/save` в группе отвечает подсказкой | Выключите privacy mode (`/setprivacy` → Disable) и заново добавьте бота в группу |
| «Трек защищён DRM» | Так SoundCloud отдаёт часть треков. Бот предложит скачать этот трек из других сервисов |
| Файл больше 50 МБ | Лимит Telegram на отправку. Выберите качество пониже в `/settings` или вырежьте фрагмент через `/crop` |
| Файл для конвертации больше 20 МБ | Лимит Telegram на скачивание файлов ботом |
| Нет конвертации документов | Образ собран с `INSTALL_LIBREOFFICE=false` |

## Разработка

```bash
./mvnw test                                                          # тесты
./mvnw test -Dconverters.it=true -Dtest=ConvertersIntegrationTest   # все конвертации на реальных файлах (нужны ffmpeg, ImageMagick, poppler, LibreOffice)
```

Новый конвертер файлов — один бин, реализующий `FileConverter`. Новый музыкальный сервис — один бин с `MusicSearchProvider` плюс значение в `MusicProvider`. Остальное подхватится автоматически.
